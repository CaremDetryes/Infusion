#EnCours 

Action de réaction : parer (art martial + bouclier s'il y a) et esquive (vivacité)
# Les actions 
Vous possédez 3 actions par tour qui se rechargent à la fin de votre tour. 
Vous pouvez utiliser 1 action pour : 
- **Mouvement** : Se déplacer de votre vitesse.
- **Attaquer** : Effectuer un autant d'attaque que vous avez de nombre d'attaque. 
- **Réagir** : Utiliser une réaction. 
- **Lancer un sort** : Lancer un sort mineur, sort de réaction ou sort qui demande une action bonus.
  **Attention !** Les autres sorts coûtent 2 actions à lancer. 
- **Observer** : Faite un jet pour avoir des informations, repérer une faiblesse, deviner les plans de l'ennemi…

Vous pouvez également utiliser l'action **Attaquer** plus d'une fois mais chaque action **Attaquer** au delà de la première se fera avec un désavantage cumulatif. Même chose pour **Lancer un sort**. 

Les capacités de classe qui vous permettent de faire de nouvelles actions bonus ou de passer certaines actions en action bonus ne coûtent pas d'action la première fois que vous les utilisez dans le tour.

# Les réactions 
Vous pouvez prendre des réactions pendant le tour de l'ennemi, chacune d'elle coûte une action, ce qui veux dire que vous aurez des points d'actions en moins au tour suivant : 
- **Esquive** : Doit être prononcé avant le jet d'attaque. Jet de vivacité augmente la le Challenge de l'attaque du nombre de succès. 
  **Attention !** Certains dégâts sont impossible à réduire avec **Esquive** (force, psychiques, poison) 
- **Parade** : Vous utilisé vos armes ou bouclier pour tenter de bloquer l'attaque, vous ajoutez 1 dé à votre jet de défense si vous utilisez une armes, ou deux si vous utilisez un bouclier.
- **Attaque d'opportunité** : Effectuer une attaque contre un ennemi qui entre dans votre zone de contrôle en mêlé.
  **Attention !** Les ennemis communs ne peuvent pas effectuer d'attaque d'opportunité, faite de cette information ce que vous voulez. 
- **Interposer** : Si un allié à 1.5m devrait se prendre une attaque vous pouvez prendre les dégâts à sa place et vous vous placez sur son emplacement. 
- **Aider** : Donnez à un allié avantage sur une attaque, lancé de capacité ou jet de sauvegarde si vous pouvez expliquer raisonnablement comment votre personnage compte aider cette action. **Attention !** Un jet ne peut être aidé qu'une seule fois en combat.

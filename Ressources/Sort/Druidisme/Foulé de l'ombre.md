**Nature** : #Utilitaire
**Coût en Mana** : 2
**Temps d'incantation** : 1 action
**Challenge** : 2
**Degré d'amplification** : 2

**Portée** : Soi-même
**Durée** : Instantanée
### Description
Vous vous fondez dans votre propre ombre avant de réapparaître en un point situé à une distance maximale égale à votre vitesse de déplacement. Ce déplacement est instantané.
### Amplifications
• **Augmentation de distance** : Vous pouvez augmentez la distance parcourue de votre vitesse de déplacement.
